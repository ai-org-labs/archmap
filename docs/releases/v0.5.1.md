# ArchMap v0.5.1

This release improves dense screen flows and playground navigation, and adds a
downloadable text catalog of all supported icon keys.

## Changes

- Separate opposing screen-flow edges when multiple actions connect the same
  screens. Additional routing lanes and arrival spacing also cover modal dialogs.
- Collapse and restore the source editor to give diagrams more space.
- Drag the diagram to pan and use the mouse wheel to zoom around the cursor.
  Fit resets the view; keyboard arrows, plus/minus, and zero are also supported.
- Download `archmap-icons.txt` from the syntax page or offline guide. It contains
  all 2,777 icon keys and names, including aliases, regardless of the search filter.
- Include these improvements in the standalone offline HTML.

## Compatibility

Existing diagram syntax remains unchanged. Core and lifecycle versions are
aligned to 0.5.1. This GitHub release does not publish packages to npm.

## Downloads

- Open `archmap-playground-v0.5.1.html` locally to use the playground offline.
- Verify the HTML with `archmap-v0.5.1-SHA256SUMS.txt`.
- [Online playground](https://ai-org-labs.github.io/archmap/playground/)
- [Syntax and icon catalog](https://ai-org-labs.github.io/archmap/syntax/)

## Verification

- Type checking, 516 tests, production builds, standalone asset checks, and
  diagram benchmarks via `npm run verify:diagrams`.
- Routing regression coverage for 2, 4, 8, and 16 opposing actions per direction,
  including mirrored layouts and modal dialogs.
- Browser checks for editor collapse, panning, cursor-centered zoom, keyboard
  navigation, fit, mobile layout, and offline use.
- Icon catalog download checks for all 2,777 unique keys, aliases, filtered
  searches, mobile layout, and offline use.
