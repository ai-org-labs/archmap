# ArchMap v0.5.2

Larger diagrams are now supported in the web playground, offline HTML, and
focused diagrams API, with faster route selection.

## Changes

- Raise limits to 400 nodes, 200 groups, 1,000 edges, and 1,000 screen actions.
- Support manual grid coordinates from 1 to 400 on each axis and source text
  up to 500,000 UTF-16 code units.
- Skip expensive collision checks for route candidates whose base cost already
  exceeds or matches the best route. Existing route selection is preserved.
- Update the syntax reference and add larger layout and performance regressions.

Existing syntax remains compatible. Nesting and text-label limits are unchanged.
Core and lifecycle versions are aligned to 0.5.2. This GitHub release does not
publish packages to npm.

## Performance and verification

- `npm run verify:diagrams`: type checking, 518 tests, production builds,
  standalone asset checks, and diagram benchmarks.
- 400-node / 200-group layout checks cover card overlaps, edge/card collisions,
  and bounds; the offline playground was also verified in Chrome.
- SVG output matched before and after route pruning across 45 sample/generated
  diagrams.
- Local benchmark p95 for parsing, layout, and SVG generation was approximately
  117 ms for 400 nodes / 200 groups and 164 ms for 400 nodes / 1,000 edges.
  These measurements exclude browser painting and depend on hardware and graph
  topology; densely crossing graphs can take longer.
