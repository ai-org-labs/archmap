# ArchMap v0.5.0

ArchMap now focuses its public playground on five readable diagram types:
system architecture, layer stacks, sequences, screen flows, and activities.
The site renders entirely in the browser; the downloadable standalone HTML
includes the editor, renderer, syntax guide, and icon assets for offline use.

## Highlights

- New focused DSL and standalone `@archmap/core/diagrams` API, with grid-based
  layout, orthogonal routing, and improved port and label placement.
- Nested structural groups using `parent=ID`, up to eight levels.
- Icon-first architecture and layer diagrams using `style icons`.
- Compact sequence participants, sender-aligned borderless labels, nested
  activation bars, and `alt`, `opt`, `loop`, and `par` / `and` fragments.
- Activity `fork` and `join` bars for parallel branches and synchronization.
- Screen action lists with row-based connector ports; explicit `action`
  declarations distinguish navigation, modal dialogs, in-screen state changes,
  local operations, and closing a modal.
- Full bundled icon coverage from the pinned ArchMap Icons 0.1.3 snapshot:
  AWS 305, Google Cloud 261, Azure 705, and 98 common services, including aliases
  such as `1password`. Package-provided letter badges remain letter badges.
- Complete searchable syntax and icon reference, copyable AI authoring prompt,
  SVG/PNG export, and a simplified overview page.

## Compatibility

The focused DSL is separate from the legacy `graph` + YAML and topology APIs.
The existing core and lifecycle implementation remains available; legacy syntax
is documented in `docs/LEGACY_SYNTAX.md`. Existing focused source remains valid.
The public site now uses Overview, Playground, Syntax, and Examples routes.

The lightweight diagrams API does not bundle vendor assets; applications can
register icon packs explicitly. The web playground and attached offline HTML
bundle their icons and require no runtime icon downloads.

The lifecycle package and descriptor are aligned to 0.5.0 and require
`@archmap/core` ^0.5.0. No npm publication is included in this GitHub release.
